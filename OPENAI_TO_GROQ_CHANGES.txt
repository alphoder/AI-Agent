================================================================================
OPENAI → GROQ + DEEPGRAM MIGRATION LOG
================================================================================
Date: 2026-03-23
Reason: OpenAI API credits expired. Using free alternatives for testing.
Reversibility: All changes are designed to be easily reversible. Search for
               "GROQ_SWAP" comment markers in code to find every change point.

================================================================================
NEW STACK:
  LLM:  Groq API (llama-3.3-70b-versatile) — OpenAI-compatible endpoint
  STT:  Deepgram (already in use, no change needed)
  TTS:  Deepgram Aura (replaces OpenAI TTS)
  Avatar: Simli Compose (no change)
================================================================================

TO REVERT BACK TO OPENAI:
  1. Set OPENAI_API_KEY in .env with a funded key
  2. Set LLM_PROVIDER=openai in .env (or remove LLM_PROVIDER entirely)
  3. Set TTS_PROVIDER=openai in .env (or remove TTS_PROVIDER entirely)
  4. Restart AI service
  That's it — the code checks LLM_PROVIDER/TTS_PROVIDER env vars and routes
  to the correct provider automatically.

ENV VARS SUMMARY:
================================================================================
GROQ_API_KEY        - Groq API key (free tier)
LLM_PROVIDER        - "groq" or "openai" (default: "openai")
TTS_PROVIDER        - "deepgram" or "openai" (default: "openai")
OPENAI_API_KEY      - OpenAI key (kept, used when LLM_PROVIDER=openai)
DEEPGRAM_API_KEY    - Deepgram key (already existed, now also used for TTS)

================================================================================
GROQ API DETAILS:
================================================================================
Endpoint: https://api.groq.com/openai/v1  (OpenAI-compatible)
Model: llama-3.3-70b-versatile
Free tier: ~6000 tokens/min, 30 requests/min
No credit card required

================================================================================
DEEPGRAM TTS (AURA) DETAILS:
================================================================================
Endpoint: POST https://api.deepgram.com/v1/speak?model=aura-asteria-en
Returns: raw audio (linear16 PCM by default)
Voices: aura-asteria-en (female), aura-orion-en (male), aura-luna-en, etc.
Free tier: $200 credits (shared with STT)
