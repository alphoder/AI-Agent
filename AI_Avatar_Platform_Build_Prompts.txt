PROMPT 3 of 10: AUTHENTICATION (SSO SAML/OIDC), JWT, AND RBAC
--------------------------------------------------------------

Build a generic SSO adapter supporting both SAML 2.0 (using @node-saml/passport-saml directly, not passport) and OIDC (using openid-client with Authorization Code Flow + PKCE). The adapter reads tenant sso_provider and routes accordingly. SAML: generate AuthnRequest, validate response signatures/audience/timestamps, extract email from NameID and groups from attributes. OIDC: discover provider, handle code exchange, validate id_token claims. Cache adapter instances per tenant.

Role resolution reads tenant sso_config.role_mapping (source field, admin_values array, default always learner). Never default to admin. Log every decision.

JWT service: RS256 access tokens (15-min, payload: sub, tid, role, email), opaque refresh tokens in Redis (7-day TTL, single-use rotation with theft detection that revokes all tokens on reuse). Cookies: refresh token is httpOnly/Secure/SameSite=Strict. Access token sent via Authorization header.

Auth routes: GET sso/init (validate tenant, redirect to IdP), POST sso/callback (validate assertion, upsert user, issue tokens, redirect with fragment token), POST refresh, POST logout, GET me. Middleware chain: auth middleware (extract+verify JWT, attach req.user), tenant middleware (set Postgres session var, cache tenant config 5min), RBAC factory rbac(...roles) returning 403 on mismatch plus rbacOwnerOrAdmin helper. Rate limiting: Redis sliding window, 100/min admin, 30/min learner, 10/min auth endpoints, 5/min session creation.

Frontend: AuthProvider context, useAuth hook, Axios interceptor with auto-refresh on 401, ProtectedRoute and AdminRoute components, login page with tenant slug routing, callback page extracting fragment token.

PROMPT 7 of 10: REAL-TIME PIPELINE (STT + LLM + AVATAR STREAMING)
------------------------------------------------------------------

This is the heart of the product. Every millisecond matters. Target: end-to-end under 2 seconds P95.

SessionOrchestrator class: manages the full lifecycle. On start: pre-warm Simli session (saves 500ms), init Deepgram WebSocket, load history from Redis, send opening message if configured. On process_audio: forward to STT. On transcript_final (CRITICAL PATH): input guardrails (<10ms), RAG vector search (<100ms), construct LLM prompt, stream response with chunk buffering, per-chunk output guardrails + avatar send, append history, persist async.

DeepgramSTTClient: nova-2 model, opus encoding, 16kHz mono, interim results enabled, 300ms endpointing (configurable), smart formatting, configurable PII redaction. Auto-reconnect on disconnect (exponential backoff 100ms to 2s, 5-second audio ring buffer). Force-finalize after 10s silence. Ignore transcripts under 3 characters.

LLMClient: GPT-4o streaming, configurable temperature/max_tokens per persona. Prompt assembly: system message (persona definition + guardrails + scenario context + communication guidelines + blocked topics + RAG context), last 10 turns from Redis, current utterance. Chunk buffering strategy: accumulate tokens until sentence boundary (.!? followed by space/end) OR 40 tokens without boundary OR stream end. Target chunk: 5-30 words. Timeout fallback after 10s, retry once on 429.

AvatarStreamManager: persistent Simli WebRTC session per training session. Pre-warm at room join not first utterance. Send text chunks via data channel, receive lip-synced video+audio via media tracks. Keepalive every 30s during silence.

LiveKitBotParticipant: joins room, subscribes to learner audio, publishes avatar video+audio. Forwards audio to STT, publishes Simli output to room. Sends data channel events: TRANSCRIPT_INTERIM, TRANSCRIPT_FINAL, AVATAR_SPEAKING, AVATAR_IDLE, SESSION_WARNING, SESSION_END, GUARDRAIL_TRIGGERED.

Redis conversation history: list of {role, content, timestamp, turn_number}, max 10 turns, 2hr TTL. Async Postgres persistence via background tasks. Per-turn latency instrumentation: stt_duration, rag_duration, llm_ttft, llm_total, avatar_first_frame, total_e2e. Publish to Prometheus.
